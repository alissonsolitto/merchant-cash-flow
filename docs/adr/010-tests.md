# Tests

## Contexto e Definição do Problema

Criação de aplicação para testes automatizados para testar apenas o essencial.

## Opções Consideradas

- Foi adotado apenas testes de integração e testes de performance usando a biblioteca NBomber.
- Testes de unidade e de arquitetura para validar dependências não foram criados. Considero que esses teste para o cenário atual não serão gerados resultados conclusívos para considerar se a aplicação está saudável ou não.

## Consequências
- Testes de unidade e integração não criados podendo quebrar a arquitetura de dependências entre projetos e validação da unidade do use case.
