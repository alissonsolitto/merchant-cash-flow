# Fragmentação banco de dados

## Contexto e Definição do Problema

Futuramente podem aparecer problemas onde será necessário utilizar técnicas para escala de banco de dados horizontal.

## Opções Consideradas

- No primeiro momento utilizar técnicas de fragmentação horizontal de dados separando por data/dia no consolidado e lançamento. Isso ajuda a disseminar a sobrecarga.

## Consequências
- Complexidade de infraestrutura e serviços para manipulação de dados.
